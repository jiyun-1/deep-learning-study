2주차 - AI가 학습하는 방법

흐름: 예측 -> 오차 확인 -> 가중치 조절 -> 반복

1. 파라미터 vs 하이퍼파라미터
- 파라미터: 모델이 학습하는 동안 내부에서 업데이트 하는 값(가중치, 편향)
- 하이퍼파라미터: 학습 전에 개발자가 설정하는 값(학습률, 손실함수, 옵티마이저)

2. Gradient Descent
- 목표: 손실함수의 값이 최소가 되는 가중치를 찾는 것
- 가중치에 대한 손실함수 미분 (x축: weight, y축: Loss)
- gradient가 양수면 가중치를 줄이고, 음수면 늘림

- Batch: 모델 학습에서 데이터를 처리하는 묶음
- 인덱스를 shuffle 한 뒤 배치에서 사용할 인덱스를 고르는 이유 <- 모델이 순서 자체를 외워서 발생하는 과적합을 방지하기 위해

3. Cost Function
- MSE: 오차의 제곱의 평균

4. Optimizer
- gradient, learning rate 등을 통해 가중치를 업데이트 함
- 상황에 따라 learning rate 조절

5. keras
- 학습 가능한 가중치로 등록하기 위해 add_weight() 이용

편미분을 통해 파라미터에 따라 얼마나 변하는지 확인
chain rule을 통해서 cost function -> 가중치
