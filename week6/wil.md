Attention에서 casual mask는 학습 중 모델이 다음에 올 토큰을 미리 보지 못하게 한다. 모델 정답에 해당하는 단어를 참조하지 않고 추론능력을 기르기 위해서

- Self-Attention은 동일한 문장에서 Q,K,V가 나온다. 자기 자신들끼리 서로를 참고하여 의미를 파악한다.
- Cross-Attention은 보통 Decoder에서 Q, Encoder에서 K,V가 나와서 서로 다른 두 데이터 간의 연관성을 파악한다. (예: 영어 <-> 한국어)

1주차: 모델이 추론한다 것은 무엇인가?
- 모델은 하나의 함수. 결국은 "원하는 결과를 내려면 어떻게 해야할까?"이고, 원하는 결과는 이미지의 분류, 텍스트의 분류, 단어 예측 등이 있다. 입력(데이터)을 받아 모델이라는 함수가 Affine Transform과 활성화 함수를 여러 층을 거쳐 처리하고, 결과를 출력한다.

2주차: 모델은 어떻게 학습하는가?
- "모델이 학습한다" 를 "정답과의 오차를 줄이도록 파라미터(가중치,편향)를 업데이트하는 과정"으로 요약할 수 있다. 무엇을 줄일지는 Cost function이, 어떻게 줄일지는 Gradient Descent가 정한다.
- 층이 선형적이면 아무리 층을 쌓아도 하나의 선형 함수가 되므로, 비선형 활성화 함수를 넣어 표현력을 확보한다. 
- 모델에 성능을 평가하기 위해 train/validation/test 데이터셋으로 나누고 학습률, 에폭, 배치 크기 등 하이퍼파라미터를 설정한다.

3주차: "이미지" 도메인의 특징과 CNN 모델 구조
- 이미지는 가까운 위치에 있는 픽셀들끼리 강한 연관성을 갖고, 같은 물체는 위치가 달라도 같은 물체이다.
- 이런 특성을 반영한 CNN은 filter을 이미지에 이동시키면서 가중합을 계산해서 feautre map을 구한다. 그 결과 feature map을 pooling으로 크기를 줄인다.

4주차: ResNet과, 사전 학습 모델을 재사용하는 방법
깊은 레이어를 갖는 모델의 성능이 더 안 좋음 ㅠㅠ.. 을 해결한 ResNet 모델을 살펴보았다.
- Residual Block: 잔차만 학습 <- 층이 쌓이면서 생기는 기울기 소실 문제 해결
- Bottleneck Block: 차원 축소했다 늘림 <- 계산량 줄임
- Batch Normalization: 층마다 활성화함수를 통과하기 전에 미니배치 단위로 정규화 
Transfer Learining: 대규모 데이터셋으로 사전 학습된 모델의 표현을 가져와 재사용하는 것
- Fine-Tuning: 사전학습 모델을 특정 목적의 데이터셋으로 재학습시키는 과정
- Data Augmentation: 기존 데이터를 변형 생성 -> 과적합 방지, 불변성 학습
- Distillation: 지식을 뽑아냄. 확률 분포까지 학습

5주차: "자연어"의 특징과 sequential data를 다루는 모델들의 발전 과정
- 자연어의 특징과 모델이 가지는 한계와 그 해결과정을 살펴보았다.
근데 특징이라는 것도 한계 속에서 알게 되는 것 같다..
순차 데이터를 어떻게 처리할까? 
- hiddent state로 문맥을 반영한 RNN -> 장기 의존성을 다루는 LSTM & GRU -> 번역 등 입출력 문장구조가 다른 문제를 해결한 seq2seq -> context vector 하나에 압축하면서 정보 손실이 생기는 문제를 해결한 Attention


이미지 처리가 신호 처리와 유사하다?
- 공간 주파수: 신호가 공간에 따라 얼마나 빠르게 변하는지를 나타낸다
- 푸리에 변환: 신호를 서로 다른 공간 주파수를 가진 복소 지수함수들의 합으로 설명한다.
즉, 푸리에 변환은 이미지를 "공간 주파수의 성분"으로 분석하게 해준다. 
"선명한 부분", "흐릿한 부분"처럼 말하는 대신 이미지를 설명할 수 있는 정확한 언어를 푸리에 변환이 제공하는 것이다.
